# Philites FC ⚽

Official single-page website of **Philites FC** — Chuka University's side in the Chuka Premier League (University Division). One Team. One Chuka. One Philites.

## Structure

- `index.html` — the entire site (HTML/CSS/JS, no build step). All editable content lives in the `CONFIG` object at the top of the `<script>` block, marked `★★★ EDITABLE SECTION`.
- `favicon.svg` / `favicon.ico` / `favicon-*.png` / `apple-touch-icon.png` / `android-chrome-*.png` / `site.webmanifest` — the favicon set referenced from `<head>`.

## Editing

Open `index.html`, search for `★★★ EDITABLE` — fixtures, results, league table, squad, news, highlights, venue, gallery and links are all in one place.
